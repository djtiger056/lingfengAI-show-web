# 零风 AI 手机模拟预览

直接打开本目录的 `index.html`，或通过静态服务器访问。首页首屏右侧通过 `index.html?embed=1` 嵌入同一手机演示。独立打开时保留完整背景和说明，嵌入时使用透明画布与紧凑留白。

打开后，对话按日常聊天的节奏逐条出现：问起近况时，对方自然发来照片；聊到想喝的饮品时，对方发来语音消息，顺带记起上次聊天说过的口味。无需先点功能按钮或输入生图、语音、记忆指令。沈屿的咖啡语音可点击播放，使用用户提供的本地录音，不自动出声；林莹莹暂保留静态语音示意。

底部是「也想看看你」「想听你说说话」「你还记得呀」等自然接话。顶部记忆按钮可管理记录，右上角更多按钮可切换角色、重播和重置。开启减少动态效果时直接展示完整对话。

演示内容：

- 一男一女角色切换：沈屿、林莹莹，各自保留本次预览中的聊天和记忆。
- 生图：聊天过程中自然出现图片消息，支持放大预览。成图复用项目现有角色图片，不联网调用模型，也不根据任意输入实时生成。
- 语音：沈屿使用 `../../assets/coffee-voice.wav`（7.52 秒，界面显示 8 秒），支持播放、暂停、结束后重播、动态波形与文字展开；同一时间只播放一条。切换角色、重播或重置对话、隐藏页面时停止播放。林莹莹没有对应录音，保留静态提示。
- 记忆：查看、删除示例记忆；发送「记住，我喜欢雨天」可在本次预览中记录，再发「还记得我喜欢什么吗？」引用。
- 消息输入、自然接话、带输入状态的自动对话、暂停、继续和重置。回复为本地预设；页面持续注明演示性质。

无 API、账号、麦克风权限或第三方依赖。状态只保存在页面内存，刷新后恢复预设。初始口味来自虚构的上次聊天，用于展示跨对话记忆，不是真实用户资料。
