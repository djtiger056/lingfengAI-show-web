03 从此启程

启程之前，
先安心了解。

关于记忆、费用与隐私，
在开始之前，把你关心的事说清楚。

✳
Ta 能一直记住所有聊天吗？+

长期记忆会整理重要信息，供后续交流参考，但可能有遗漏或偏差，不保证记住全部聊天。你可以按角色查看、管理记忆，也可以导出备份、导入恢复。

主动消息需要哪些设置？+

在 App 内开启主动消息，再调整主动频率和每日上限。后台送达受系统通知权限、省电策略、网络与运行状态影响；进程结束或设备关机后，不保证仍能生成和送达新消息。

可以自己设定角色或导入角色卡吗？+

可以在 App 内设置角色名字、性格、背景和说话方式，也支持 .lfcard、PNG 和 JSON 角色卡导入。选择文件后先查看预览，兼容内容以 App 内导入结果为准。

使用零风，需要付费或准备 API 吗？+

普通用户使用官方 AI 服务，无需自行准备 API。内测赠送一定体验积分，相关 AI 服务会消耗积分，具体额度、使用条件与消耗规则以 App 内说明为准。

安卓内测版怎么安装？+

从本页下载入口获取 APK，打开安装包，按系统提示允许「安装未知应用」。安装后登录查看积分，选择角色即可开始。iOS 和 Web 版本尚未开放。

对话和记忆数据如何处理？+

使用在线 AI 功能时，必要的对话上下文、角色设定与相关记忆可能随请求发送给对应服务商；聊天、记忆、同步和备份会按你使用的功能处理。详情请阅读《隐私政策》，了解数据流向与导出、删除、注销方式。请妥善保管备份，避免提供密码、验证码等敏感信息。
