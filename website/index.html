05还有一点，想告诉你

关于零风，
你可能还想知道。

开始之前，把疑问慢慢说清楚。

零风AI 是什么？
零风AI 是一个围绕角色互动、长期记忆、主动陪伴与语音交流的 AI 伙伴平台。
真的会记住之前说过的话？
记忆引擎会整理对话中的重要信息，为后续交流提供上下文。记忆可能存在遗漏或偏差，具体效果与可用设置以 App 内为准。
支持语音和通话吗？
支持语音消息与通话等交流方式，具体开放情况与可用能力以 App 内入口和服务状态为准。
可以自己创建角色吗？
可以，支持设定名字、性格、说话方式和互动偏好。你可以先看看角色创建示例。
我的数据安全吗？
请在使用前阅读 App 内的隐私政策，了解对话内容的处理、存储与使用方式。请勿在对话中提供密码、验证码等敏感信息。
公测期间如何使用积分？
公测赠送一定积分，相关 AI 服务仍按规则消耗积分。具体额度与规则见公测积分说明。
可以自行配置 API 吗？
不支持。App 统一使用官方 AI 服务，不开放自行配置 API 的入口。
安卓公测版怎么安装？
下载 APK 后，按系统提示允许「安装未知应用」；安装完成后登录，查看积分并选择角色。详细步骤见下载说明。
