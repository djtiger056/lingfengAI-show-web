# 零风AI「Love Letter」UI 设计系统

版本：1.0  
适用范围：品牌官网、Android App、运营页面与产品原型

## 1. 设计理念

关键词：浪漫、温暖、亲密、克制、可信。

设计表达采用“恋爱手账 + 海盐汽水 + 晨光”的组合：柔雾粉表达亲密，珊瑚粉强调心动，近白水蓝建立轻盈层级，清透青负责行动反馈，暖阳黄只点亮关键瞬间。爱心、丝带、花瓣只出现在首屏、情绪卡片和转化区，不进入长文本与高频操作区域。

原则：

1. 浪漫服务于理解，不遮挡内容。
2. 每个页面只有一个主行动。
3. 粉色不是唯一状态提示，必须配合图标或文字。
4. 动效用于回应用户操作，不持续制造视觉噪音。
5. 亲密感与隐私控制同时呈现。

## 3. 字体系统

- 正文与功能文字：`Noto Sans SC`，字重 400 / 500 / 600 / 700。
- 标题与情绪短句：`Noto Serif SC`，字重 500 / 600 / 700，用克制的编辑感代替廉价手写感。
- 同一页面不使用第三种字体；英文功能标签沿用无衬线字体并增加字距。

字号比例：

| 层级 | 桌面 | 移动 | 行高 |
|---|---:|---:|---:|
| Hero | 70px | 36–48px | 1.14–1.18 |
| H2 | 58px | 34px | 1.18 |
| H3 | 24–31px | 23px | 1.35 |
| Lead | 17–19px | 16px | 1.8 |
| Body | 16px | 16px | 1.65–1.8 |
| Caption | 10–13px | 10–13px | 1.5 |

正文单行长度控制在 65–75 个字符以内。手写体不可用于按钮、表单或长段落。

## 4. 布局与间距

- 基础单位：4px；主要节奏使用 8 / 16 / 24 / 32 / 48 / 64 / 96px。
- 内容最大宽度：1200px。
- 移动端水平安全间距：16px。
- 桌面关键页采用 12 栏栅格；移动端单栏，平板可双栏。
- 固定导航必须预留顶部空间；底部下载条使用 `env(safe-area-inset-bottom)`。
- 所有可触控元素最小 44 × 44px。

## 5. 圆角、描边与阴影

| Token | 数值 | 用途 |
|---|---:|---|
| `radius-sm` | 12px | 标签、小控件 |
| `radius-md` | 20px | 通知、输入框 |
| `radius-lg` | 32px | 内容卡片 |
| `radius-xl` | 44px | 主舞台、转化区 |
| `radius-pill` | 999px | 按钮、状态标签 |

恋爱系识别细节：品牌图标与功能图标可使用“右下角收紧”的不对称圆角，例如 `16px 16px 16px 7px`。

阴影分三级：

- S：`0 2px 5px rgba(92,49,70,.05), 0 8px 24px rgba(118,67,90,.07)`
- M：`0 4px 10px rgba(92,49,70,.06), 0 20px 46px rgba(118,67,90,.11)`
- L：`0 10px 28px rgba(92,49,70,.08), 0 40px 92px rgba(118,67,90,.16)`

## 6. 装饰语言

- 爱心：用于心动、收藏、关系与主动想念，不作为普通项目符号。
- 丝带：用于公测、专属关系或庆祝标签；每屏最多一个。
- 花瓣：只作为边缘背景，透明度 20%–50%，不可覆盖文本和按钮。
- 曲线：使用细描边或大面积柔和渐变，不使用复杂波浪分割影响滚动节奏。
- 图标：统一使用 Font Awesome，禁止使用 emoji 充当图标。

### 材质层级

- 页面底层使用极淡纸张微纹理；透明度不得影响正文清晰度。
- 浮层采用“1px 内沿高光 + 低透明描边 + 两级柔影”，避免只靠模糊玻璃制造质感。
- 设备框体、角色主舞台和下载区属于最高层级，可使用更长的环境阴影；普通信息卡不得使用同等级阴影。
- 卡片错位控制在 16–24px，移动端恢复整齐单列，避免产生横向溢出。

### 文案声音

- 先写具体生活片段，再表达产品能力。例如用“你上周说雨天睡不好”证明记忆，而不是重复“长期记忆”。
- 标题要形成观点或反差，例如“真正让人心动的，从来不是秒回”；避免“开启美好体验”一类空泛口号。
- 按钮以动作和结果命名，例如“现在去见 Ta”“下载并遇见 Ta”，不使用“确认”“立即体验”等模糊动词。
- 浪漫不等于堆砌“温柔、心动、陪伴”。每个段落最多保留一个抽象情绪词，其余内容用时间、动作和细节落地。

## 7. 组件库

### 主按钮

- 高度：48px，核心 CTA 为 56px。
- 背景：`aqua-highlight` 到高白度水青的轻微渐变。
- 默认：`ink-900` 深色文字；Hover：提高亮度并上移 2px；Pressed：缩放至 0.98；Focus：3px 水蓝焦点环。
- 按钮文案以动词开头，例如“下载安卓公测版”“认识这个角色”。

### 次按钮

- 雾霭蓝背景、深水蓝文字、1px 同色透明描边。
- 不与主按钮争夺对比度。

### 导航

- 浮动奶油白玻璃层，离视口边缘 8–12px。
- 当前区域使用深水蓝短下划线；移动端菜单使用大触控行。

### 角色选择器

- 头像 36px，组件高度不小于 48px。
- 选中态同时改变描边、文字和背景，不能只依赖颜色。
- 支持左右方向键切换。

### 情绪通知卡

- 白色 90% 以上不透明度，M 级阴影。
- 图标区使用柔雾粉或雾霭蓝；时间为 caption，主消息不低于 13px。

### 聊天气泡

- Ta：珍珠白背景、左下角 5px；用户：珊瑚粉渐变与深色文字、右下角 5px。
- 单条消息最大宽度 84%；连续出现时使用 180–240ms 淡入上移动效。

### FAQ

- 整行可点击，高度不小于 76px。
- 展开态图标旋转 45°，正文使用网格行过渡；支持键盘操作。

### 下载浮条

- 仅在移动端滚动 420px 后出现。
- 避开底部安全区，包含版本信息与唯一主 CTA。

## 8. 动效规范

| 动效 | 时长 | 缓动 |
|---|---:|---|
| 点击反馈 | 100–180ms | ease-out |
| 卡片与按钮 | 150–220ms | ease-out |
| 内容进入 | 420–560ms | `cubic-bezier(.16,1,.3,1)` |
| 页面切换 | 300–420ms | `cubic-bezier(.16,1,.3,1)` |
| 心跳 | 1700ms 循环 | ease-in-out |

持续动效仅保留一处主心跳与低频呼吸环。系统启用 `prefers-reduced-motion` 时，循环动画和进入位移必须关闭。

## 9. 关键页面设计稿

### A. 品牌落地页

结构：浮动导航 → 情绪化 Hero → 信任信息 → 记忆/主动/定制能力 → 角色选择 → 真实 App 截图 → 下载 → FAQ。

主行动：下载安卓公测版。装饰集中在 Hero 与下载区。

### B. 对话页

结构：关系状态栏 → 对话流 → 记忆提示 → 输入区。用户气泡使用珊瑚粉，Ta 使用珍珠白；输入区固定并适配 Android 底部安全区。

### C. 发现页

结构：搜索 → 今日推荐 → 角色卡 → 创建角色入口。角色卡以人物和关系描述为主，标签最多三个。

### D. 个人中心

结构：身份卡 → 隐私与记忆 → 声音与语音 → 数据备份 → 帮助。高风险操作不使用恋爱装饰，删除动作使用明确文字与二次确认。

## 10. 可访问性与验收

- 正文对比度不低于 4.5:1，大字与 UI 边界不低于 3:1。
- 所有图标按钮具有 `aria-label`。
- 图片必须有描述性 alt；纯装饰图标使用 `aria-hidden="true"`。
- 键盘 Tab 顺序与视觉顺序一致，焦点环始终可见。
- 375px、768px、1024px、1440px 均无横向滚动。
- 不用颜色作为唯一状态指示。
- 所有图片预留尺寸或固定比例，避免布局跳动。
- 全部交互动效仅使用 `transform` 与 `opacity`。
